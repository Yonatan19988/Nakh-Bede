# لوگوی «نخ بده» (SVG)

| فایل | کاربرد |
| --- | --- |
| `logo-full.svg` | نسخه‌ی اصلی با بافت نخ (حدود ۳٫۷ مگابایت). برای چاپ، بنر و چیزهای بزرگ. از روی `assets/logo.webp` با ردیابی رنگی ساخته شده؛ بافت تقریبی است و عین عکس نیست. |
| `logo-simple.svg` | نسخه‌ی ساده و سبک (حدود ۱۱۸ کیلوبایت): خط دور تیره، حاشیه‌ی طلایی، پرشدن نارنجی و الگوی بافت ملایم. برای اندازه‌ی کوچک، وب و آیکن. |
| `logo-mono.svg` | فقط سایه‌ی تک‌رنگ (رنگ با `currentColor` عوض می‌شود). برای مهر، حکاکی، چاپ سیاه‌وسفید و پس‌زمینه‌ی روشن. |

لوگوی داخل بازی همچنان `assets/logo.webp` است و این فایل‌ها فعلاً در برنامه استفاده نمی‌شوند.
